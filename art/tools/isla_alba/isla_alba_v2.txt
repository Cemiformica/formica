// Isla Alba — plano de texto (C5.1). Una línea por fila de casillas (norte arriba), un carácter por casilla.
// 1 casilla = 1 m. Las líneas que empiezan por // son comentarios. Se puede editar a mano: el juego construye
// la isla a partir de este archivo (C5.3).
//
//  ~  mar                                ,  playa (baja; se anda, no se construye)
//  .  parte baja (se anda, no se construye)
//  =  explanada baja (plana; se construye)        nivel 0
//  ^  parte alta (se anda, no se construye)
//  #  explanada alta (plana; se construye)         nivel 1 (unos 6 m más)
//  /  cuesta: ladera que sube de la parte baja a la alta (se anda, no se construye)
//  _  rellano de la cuesta (mirador a media altura)
//  :  sendero de la ladera (como la cuesta, pero se pinta de tierra pisada; se puede mover o quitar)
//  O  lago de arriba (agua quieta, nivel 1)       o  remanso de abajo (agua quieta, nivel 0)
//  v < >  río que corre hacia el sur, el oeste o el este (nivel 0)
//  C  cascada (del lago al río; decorado que se dibuja)
//  s  vado de piedras planas (sobre el río: se cruza sin mojarse)
//  R  refugio (cueva-hormiguero en el acantilado; su planta de casillas, en la hoja del refugio)
//  P  portal (Umbral Raíz)
//  M  veta de malaquita (3 × 3)                   S  veta de piedra (3 × 3)
//  T  arboleda (3 × 3, con sitio para un talador en el borde de la explanada)
//  t  árbol salvaje (sobre el terreno de alrededor: montaña, parte baja o ladera)
//  X  peñasco (afloramiento de roca modelado; no se pasa)
//  A  arco de roca (decorado; se pasa por debajo)
//  G  árbol singular (2 × 2; enorme y viejo, se ve desde toda la isla)
//  H  restos de la colonia antigua (columnas hexagonales medio enterradas; decorado)
//  Q  boca de la cueva marina (juego completo)          E  embarcadero en ruinas (juego completo; la barca, D-157)
